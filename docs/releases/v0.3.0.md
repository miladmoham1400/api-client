# Offline API Client 0.3.0

A new dark glass interface and a simpler request/response workflow for Linux and Windows. Unsigned pre-release; existing workspaces and saved requests are preserved.

## New in this release

- Dark glass panels, refined colors and spacing, a compact toolbar and clearer request selection. New profiles default to Dark; existing Light/Dark/System preferences are preserved.
- Request and response panels start side by side, with an icon layout toggle and a draggable, keyboard-accessible divider.
- Automatic saving after a short idle interval, including a save flush before switching requests or closing normally. Failed or invalid saves retain recovery controls; Ctrl+S retries immediately. Requests are sent only when explicitly requested.
- Pretty responses by default, with collapsible JSON objects/arrays and Raw fallback for large or invalid JSON.
- An isolated static HTML preview for readable server error pages, including Laravel-style errors. Scripts and external resources remain blocked; JavaScript-rendered pages may require Raw inspection.
- Two-space Tab insertion in the JSON body editor, optional details instead of long helper text, compact response status/time/size and request actions in sidebar menus.
- Retains nested collections/folders, workspace search, method colors, safe import/export and local-only storage.

## Downloads

Use the `.deb` on Ubuntu 24.04 x64, `.exe` on Windows x64, or Linux x64 AppImage. Verify the installers with `SHA256SUMS.txt`. Installation requires no developer Node/npm or account.

## Verification and limits

Publication requires fresh native Ubuntu 24.04 and Windows Server 2022 builds from the same source commit, unit checks, actual deb/NSIS installation and focused installed-app checks. The publisher verifies provenance and every installer SHA-256 before uploading assets. Build results will be recorded here before publication.

These hosted checks do not establish Windows 11 acceptance. Full offline/manual native chooser and uninstall/reinstall verification is not repeated for these installer bytes; default AppImage FUSE launch remains unverified. Packages are unsigned and Windows may show reputation prompts. Automatic saving does not guarantee recovery of edits after abrupt process termination. No automatic updates, telemetry, cloud sync, multiple tabs, scripting or OAuth are added. The repository retains its `UNLICENSED` designation.
