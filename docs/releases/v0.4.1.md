# Offline API Client 0.4.1

Interface and library fixes for the dark glass desktop client. Unsigned pre-release for Linux and Windows. Existing saved workspaces remain supported.

## Changes

- Consistent themed tooltips with pointer/keyboard support and Escape dismissal.
- Compact library rows with a unified hover surface and refreshed HTTP method chips.
- Import/export dialogs close after success; import cancellation is silent.
- Typed Bearer values remain readable after autosave, with colored variable placeholders and name completion. Basic passwords remain masked; stored credential values remain protected on navigation/restart.
- JSON Body line numbers stay synchronized while scrolling. Syntax warnings appear below the Body editor, above Body details.
- **Duplicate folder** copies all nested folders and saved requests, including empty folders, with fresh identities and independently owned credentials. The copy is transactional and leaves the selected request unchanged.
- Retains Body variants, Postman Collection v2.1 JSON transfer, autosave, safe static HTML preview, expanded Pretty JSON, exact-response copying and offline local storage. No automatic request sending, runtime cloud dependency or updater.

## Downloads and verification

Choose `.deb` for Ubuntu 24.04 x64, `.exe` for Windows x64, or `.AppImage` for Linux x64; verify `SHA256SUMS.txt`. Installed use needs no developer Node/npm or account.

Publication requires fresh native Ubuntu 24.04 and Windows Server 2022 builds from one source commit, unit checks, actual deb/NSIS installation and the focused installed-app test suite, now including the interface/Bearer/Body/folder-duplication regression. The publisher validates source provenance and all installer hashes before upload. Source/build commit: `85d10b7f215b6dae03a3c458c91abcc31231c4b4`. [Successful native builds and installed checks](https://github.com/miladmoham1400/api-client/actions/runs/41708682593):

- Ubuntu 24.04 x64: 387 unit tests and 20 installed-app tests passed.
- Windows Server 2022 x64: 386 unit tests and 20 installed-app tests passed; one native upload-permission fixture skipped (not a pass).
- With 1,000 requests and 1,000 folders, cold readiness / selection p95 / search p95 measured 1226.06 / 250.55 / 168.43 ms on Linux and 1166.59 / 232.42 / 149.44 ms on Windows, within the unchanged existing thresholds.

Hosted Windows Server checks do not establish Windows 11 acceptance. Full network-isolated/manual native chooser and uninstall/reinstall acceptance is not repeated for these installer bytes. Default AppImage FUSE launch and actual Postman GUI import remain unverified. Transfer integration tests control native chooser responses while using real IPC/file services. Packages are unsigned; Windows may show reputation prompts.

Postman support remains the documented Collection v2.1 JSON subset. Scripts/OAuth and unsupported modes are not imported/executed. Credentials, sensitive variable values and file paths/selections are omitted from exports; ordinary URL/query/body/plain-variable text can still contain user-entered secrets, so review files before sharing. Body profiles require 0.4.0 or newer readers. Secure OS storage or session-only fallback remains unchanged. The repository retains its `UNLICENSED` designation.
