# Offline API Client 0.2.0

An unsigned pre-release for Linux and Windows. Installed startup and local data operations require no account, cloud service or developer Node/npm.

## New in this release

- Organize many saved APIs in collections with nested folders and contextual creation, rename, move and delete actions.
- Browse an expandable tree, quickly search requests and select any saved API for explicit sending in one editor.
- Preserve legacy libraries and transfer nested libraries with hierarchy-aware workspace JSON import/export.
- Recognize GET, POST, PUT, PATCH, DELETE, HEAD and OPTIONS by distinct colors in the tree, search and method selector.
- Includes readable JSON highlighting, a custom app icon and adjustable stacked or side-by-side request/response panels.
- Fixes guarded navigation dialogs and Ctrl+S handling with non-Latin keyboard input.

## Downloads

Use the `.deb` on Ubuntu 24.04 x64, the `.exe` on Windows x64, or the Linux AppImage. Verify downloads with `SHA256SUMS.txt`. [Installation instructions](https://github.com/miladmoham1400/api-client/blob/master/README.md).

## Verification and limits

Publication requires a successful native build on Ubuntu 24.04 and Windows Server 2022 from the tagged source commit, unit checks, actual package installation and focused installed-app tests covering SQLite, IPC security, JSON display, panel layout, responses, requests, folders, tree navigation, search, legacy migration and large-library performance. The publication workflow checks all installer SHA-256 values before upload. Refer to the repository's Actions runs for actual results and skips; skipped checks are not passes.

Windows Server checks do not establish Windows 11 acceptance. Full offline/manual native chooser and uninstall/reinstall verification has not been repeated for these new installer bytes; earlier milestone acceptance applies to its separately hashed packages. Native permission-denial fixtures may be skipped on elevated runners. AppImage default FUSE launch remains unverified; the hosted installed checks target the deb. Packages are unsigned and Windows may show reputation prompts. No automatic updates, cloud sync, multiple tabs, scripting or OAuth are included. The repository retains its `UNLICENSED` designation.
