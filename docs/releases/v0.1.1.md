Offline API Client is a local desktop HTTP client for Linux and Windows. Installed local operations require no developer Node/npm, account or cloud service.

This pre-release includes a custom application icon, readable JSON highlighting, and resizable stacked or side-by-side request/response panels.

Download the `.deb` for Ubuntu 24.04 x64, or the unsigned `.exe` for Windows x64. The AppImage is an alternative Linux package; extraction-and-run mode was tested locally, default FUSE mounting remains unverified. Check downloads using `SHA256SUMS.txt`.
