# Offline API Client 0.6.0

Unsigned desktop pre-release for Linux x64 and Windows x64.

## Changes

- Drag saved requests onto folders. Drag folders onto other folders or collection roots to move their entire subtree.
- Resize the workspace and request explorer by dragging the sidebar divider.
- Request tabs share one width and show full names on hover. The layout toggle sits beside the tab strip.
- The URL and Send bar stays accessible when scrolling request fields. Send shows an inline spinner, and Cancel appears in the Response panel during execution.
- JSON Body editing uses CodeMirror commands for indentation and paired braces, brackets and quotes. Variable completion remains available.
- The response body view follows each request during the app session, including across repeated sends and tab switches.
- Expected response JSON saves automatically. Clearing the field removes the expectation and restores the informational notice.

## Downloads

Use the .deb on Ubuntu 24.04 x64, the AppImage on Linux x64, or the NSIS .exe on Windows x64. The release includes SHA256SUMS.txt for verifying the installers. Installed use requires no Node.js, account or internet access for local operations.

The publication workflow requires both native installer builds and their installed-app checks to pass. Its installed tests exercise the deb and Windows installer. AppImage launch, Windows 11 and uninstall/reinstall have separate verification requirements.
